# Samuel Smith Mechanical Engineering Portfolio — Burgundy / Pewter Theme

This version keeps the current Alloy layout, headshot placement, project carousels, and manual Light/Dark appearance toggle, but updates both appearances around the supplied palette:

- Soft White: #F2EBEC
- Cool Gray: #858A91
- Pewter: #94979A
- Burgundy: #2E1110

## Appearance behavior
- First visit: follows the visitor's system/browser light/dark preference automatically.
- Toggle: manually switches between Light and Dark only.
- Manual choice: saved in localStorage as `portfolio-theme`.
- If no manual choice exists, system appearance changes continue to be followed.

## Theme direction
- Dark: deep burgundy foundation, soft-white type, pewter controls, cool-gray secondary elements.
- Light: crisp white foundation, burgundy typography/primary controls, soft-white surfaces, cool-gray/pewter secondary elements.

## Project images
Replace the SVG placeholder files in `images/` with your real project photos while preserving the filenames, or update the corresponding image paths in `index.html`.
